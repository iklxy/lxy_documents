## 二、简答题答案

### 第 1 题

相同点：二者都常用于最优化问题，都要求问题具有最优子结构性质。

不同点：动态规划会系统求解并保存相关子问题答案，适合有重叠子问题且需要全局比较的情形；贪心算法每一步做局部最优选择，通常自顶向下迭代推进，不回头修改选择，效率较高，但必须证明贪心选择能导向全局最优。

### 第 2 题

最优子结构是指一个问题的最优解包含其子问题的最优解。若该性质不成立，就无法通过求解较小子问题来构造原问题最优解。

动态规划依赖最优子结构建立状态转移；贪心算法依赖它说明作出一次贪心选择后，剩余部分仍是同类子问题，并可继续最优求解。

### 第 3 题

回溯法通常用于找出满足约束条件的解或所有解，也可求最优解；它按深度优先方式搜索解空间树，并在搜索中利用约束函数和限界函数剪枝。

分支限界法通常用于最优化问题，常以广度优先或最小耗费/最大效益优先方式搜索；每个活结点一般只有一次机会成为扩展结点，活结点常由队列或优先队列组织。

### 第 4 题

1. $T(n)=2T(n/2)+O(n)$：$a=2,b=2,n^{\log_b a}=n$，故 $T(n)=O(n\log n)$。
2. $T(n)=3T(n/2)+O(n)$：$n^{\log_2 3}$ 高于 $n$，故 $T(n)=O(n^{\log_2 3})$。
3. $T(n)=T(n-1)+O(n)$：展开为 $O(n+(n-1)+\cdots+1)=O(n^2)$。

## 三、算法设计题答案

### 第 1 题：分治法求最大子数组和

把区间 $[l,r]$ 分成 $[l,mid]$ 和 $[mid+1,r]$。最大子数组只可能在左半部分、右半部分，或跨越中点。

跨越中点的最大和可由两段组成：

- 从 `mid` 向左扫描，求最大后缀和 `leftBest`。
- 从 `mid+1` 向右扫描，求最大前缀和 `rightBest`。

则跨中点答案为 `leftBest + rightBest`。

递归返回：

```text
solve(l, r):
    if l == r: return A[l]
    mid = (l + r) / 2
    left = solve(l, mid)
    right = solve(mid + 1, r)
    cross = max_suffix(l, mid) + max_prefix(mid + 1, r)
    return max(left, right, cross)
```

递归式为 $T(n)=2T(n/2)+O(n)$，故时间复杂度 $O(n\log n)$，递归栈空间 $O(\log n)$。

### 第 2 题：动态规划零钱兑换

设 $dp[j]$ 表示凑成金额 $j$ 所需的最少硬币数。边界条件：

$$
dp[0]=0,\quad dp[j]=+\infty \ (j>0).
$$

转移方程：

$$
dp[j]=\min_{coin\in coins,\,j\ge coin}\{dp[j-coin]+1\}.
$$

算法：

```text
dp[0] = 0
for j = 1..amount:
    dp[j] = INF
    for coin in coins:
        if j >= coin:
            dp[j] = min(dp[j], dp[j - coin] + 1)
return dp[amount] if dp[amount] != INF else -1
```

时间复杂度 $O(amount\cdot |coins|)$，空间复杂度 $O(amount)$。

### 第 3 题：贪心跳跃游戏

维护当前能够到达的最远下标 `far`。从左到右扫描，若当前位置 `i > far`，说明无法到达 `i`，返回 false；否则更新：

$$
far=\max(far,i+nums[i]).
$$

若扫描过程中 `far >= n-1`，返回 true。

```text
far = 0
for i = 0..n-1:
    if i > far:
        return false
    far = max(far, i + nums[i])
    if far >= n - 1:
        return true
return true
```

正确性：扫描到位置 $i$ 时，`far` 表示只使用前 $i$ 个可达位置时能到达的最远位置。若 $i>far$，任何已扫描位置都无法跳到 $i$，后续位置也无法被访问，故不可能成功。若 $i\le far$，位置 $i$ 可达，用它更新最远可达范围不会丢失任何可行方案。因此算法正确。

时间复杂度 $O(n)$，空间复杂度 $O(1)$。

### 第 4 题：搜索岛屿数量

遍历每个格子。若遇到未访问的陆地，就把答案加 1，并从该格子开始 DFS/BFS，把同一连通块中的陆地全部标记为已访问。

DFS：

```text
ans = 0
for each cell (i, j):
    if grid[i][j] == '1' and not visited[i][j]:
        ans += 1
        dfs(i, j)

dfs(i, j):
    if 越界或不是陆地或已访问: return
    visited[i][j] = true
    dfs(i + 1, j)
    dfs(i - 1, j)
    dfs(i, j + 1)
    dfs(i, j - 1)
```

每个格子最多访问一次，时间复杂度 $O(mn)$，空间复杂度 $O(mn)$；若直接把访问过的陆地改为 `'0'`，可不另开 visited 数组，但递归栈最坏仍为 $O(mn)$。

### 第 5 题：单纯形法求生产计划

线性规划模型为：

$$
\max z=40x+30y
$$

$$
\begin{aligned}
2x+y+s_1&=40,\\
x+y+s_2&=30,\\
x+s_3&=18,\\
x,y,s_1,s_2,s_3&\ge 0.
\end{aligned}
$$

初始单纯形表：

| 基变量 | $b$ | $x$ | $y$ | $s_1$ | $s_2$ | $s_3$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| $s_1$ | 40 | 2 | 1 | 1 | 0 | 0 |
| $s_2$ | 30 | 1 | 1 | 0 | 1 | 0 |
| $s_3$ | 18 | 1 | 0 | 0 | 0 | 1 |
| $C_j-Z_j$ |  | 40 | 30 | 0 | 0 | 0 |

$x$ 入基，按最小比值 $40/2,30/1,18/1$，$s_3$ 出基：

| 基变量 | $b$ | $x$ | $y$ | $s_1$ | $s_2$ | $s_3$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| $s_1$ | 4 | 0 | 1 | 1 | 0 | -2 |
| $s_2$ | 12 | 0 | 1 | 0 | 1 | -1 |
| $x$ | 18 | 1 | 0 | 0 | 0 | 1 |
| $C_j-Z_j$ |  | 0 | 30 | 0 | 0 | -40 |

$y$ 入基，$s_1$ 出基：

| 基变量 | $b$ | $x$ | $y$ | $s_1$ | $s_2$ | $s_3$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| $y$ | 4 | 0 | 1 | 1 | 0 | -2 |
| $s_2$ | 8 | 0 | 0 | -1 | 1 | 1 |
| $x$ | 18 | 1 | 0 | 0 | 0 | 1 |
| $C_j-Z_j$ |  | 0 | 0 | -30 | 0 | 20 |

$s_3$ 入基，$s_2$ 出基：

| 基变量 | $b$ | $x$ | $y$ | $s_1$ | $s_2$ | $s_3$ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| $y$ | 20 | 0 | 1 | -1 | 2 | 0 |
| $s_3$ | 8 | 0 | 0 | -1 | 1 | 1 |
| $x$ | 10 | 1 | 0 | 1 | -1 | 0 |
| $C_j-Z_j$ |  | 0 | 0 | -10 | -20 | 0 |

检验数均不为正，达到最优。由最后一张表读出：

$$
x=10,\quad y=20.
$$

最大利润：

$$
z=40\times 10+30\times 20=1000.
$$
