给定 $n$ 天股票价格 $p[1],p[2],\dots,p[n]$。每天最多进行一次操作，操作为买入、卖出或不操作；同一时刻最多持有一股股票；允许多次买卖，但卖出后才能再次买入。请用动态规划求最大收益，要求描述算法、给出边界条件和状态转移方程，并分析复杂度。

## 二、简答题答案

### 第 1 题

霍夫曼树构造过程每次选取权值最小的两棵树合并：

1. 合并 A(5) 与 B(9)，得 14。
2. 合并 C(12) 与 D(13)，得 25。
3. 合并 14 与 E(16)，得 30。
4. 合并 25 与 30，得 55。
5. 合并 F(45) 与 55，得 100。

令左边记 0、右边记 1，可得到一种编码：

| 字符 | 编码 |
| --- | --- |
| F | 0 |
| C | 100 |
| D | 101 |
| A | 1100 |
| B | 1101 |
| E | 111 |

编码串 `11001101111` 可按前缀码从左到右唯一解码为：

`1100 1101 111`

所以解码结果为 `ABE`。若考试中题目给出另一组字符频率，应先按频率重新构造霍夫曼树，再按对应编码表解码。

### 第 2 题

普通线性规划可以用单纯形法求解，但 0-1 背包问题本质上是整数规划：变量 $x_i$ 只能取 0 或 1，约束为

$$
\max \sum_{i=1}^{n} v_i x_i,\quad
\sum_{i=1}^{n} w_i x_i\le C,\quad x_i\in\{0,1\}.
$$

若把 $x_i\in\{0,1\}$ 放松为 $0\le x_i\le 1$，单纯形法求得的是分数背包的线性规划松弛解，可能出现“取一部分物品”的情况，不一定是原 0-1 背包的可行解。因此，直接用单纯形法不是求解 0-1 背包的合适方法。0-1 背包通常用动态规划、回溯法、分支限界法或整数规划方法求解。

### 第 3 题

P 问题是指存在确定性算法，能在输入规模的多项式时间内求解的问题。

NP 问题是指对任意给定的候选解，能够在输入规模的多项式时间内验证该解是否正确的问题。等价地说，NP 问题可由非确定性算法在多项式时间内求解。

### 第 4 题

1. $T(n)=4T(n/2)+O(n)$。由主定理，$a=4,b=2$，$n^{\log_b a}=n^2$，且 $f(n)=O(n)=O(n^{2-\epsilon})$，故 $T(n)=O(n^2)$。
2. $T(n)=T(n/2)+O(1)$。每次规模减半，共 $O(\log n)$ 层，每层 $O(1)$，故 $T(n)=O(\log n)$。
3. $T(n)=4T(n-1)+O(1)$。展开得 $T(n)=4^kT(n-k)+O(1+4+\cdots+4^{k-1})$，取 $k=n-1$，得 $T(n)=O(4^n)$。

## 三、算法设计题答案

### 第 1 题：动态规划股票购买问题

设：

- $dp0[i]$：第 $i$ 天结束时不持有股票的最大收益。
- $dp1[i]$：第 $i$ 天结束时持有一股股票的最大收益。

边界条件：

$$
dp0[0]=0,\quad dp1[0]=-\infty.
$$

转移方程：

$$
dp0[i]=\max(dp0[i-1],dp1[i-1]+p[i])
$$

表示第 $i$ 天结束不持股：要么昨天也不持股，要么今天卖出。

$$
dp1[i]=\max(dp1[i-1],dp0[i-1]-p[i])
$$

表示第 $i$ 天结束持股：要么昨天已持股，要么今天买入。

答案为 $dp0[n]$。时间复杂度 $O(n)$，空间复杂度可由 $O(n)$ 优化为 $O(1)$。

若考试题限制为“最多交易一次”，可改用：

$$
hold[i]=\max(hold[i-1],-p[i]),\quad sold[i]=\max(sold[i-1],hold[i-1]+p[i]).
$$

### 第 2 题：贪心设置邮局

先将住户距离升序排序。维护最左侧尚未覆盖的住户 $H[i]$，在 $H[i]+100$ 处设置一个邮局。该邮局能覆盖区间

$$
[H[i], H[i]+200].
$$

然后跳过所有距离不超过 $H[i]+200$ 的住户，继续处理下一个未覆盖住户，直到所有住户被覆盖。

算法：

```text
sort(H)
i = 1
ans = []
while i <= n:
    left = H[i]
    ans.append(left + 100)
    while i <= n and H[i] <= left + 200:
        i += 1
return ans
```

正确性证明：设 $H[i]$ 是当前最左未覆盖住户。任何可行方案都必须有某个邮局覆盖它，该邮局位置至多为 $H[i]+100$。把这个邮局右移到 $H[i]+100$ 不会失去对 $H[i]$ 的覆盖，并且只会扩大右侧覆盖范围。因此存在一个最优解第一座邮局放在 $H[i]+100$。选定后，问题缩小为覆盖剩余未覆盖住户，递归应用同样论证，贪心得到最优解。

排序后扫描，时间复杂度 $O(n\log n)$；若输入已排序，则为 $O(n)$。

### 第 3 题：圆钢切割

设每根原材料最多可切出 $a$ 根 2.5 米钢柱和 $b$ 根 1.3 米钢柱，则

$$
2.5a+1.3b\le 8.
$$

可用的高利用率切割方式包括：

| 方式 | 2.5 米根数 | 1.3 米根数 | 使用长度 |
| --- | ---: | ---: | ---: |
| A | 3 | 0 | 7.5 |
| B | 2 | 2 | 7.6 |
| C | 1 | 4 | 7.7 |
| D | 0 | 6 | 7.8 |

注意每根原材料若切出 $a$ 根 2.5 米钢柱，则最多能切出的 1.3 米钢柱数不超过 $6-2a$。若使用 $N$ 根原材料，且总共需要 300 根 2.5 米钢柱，则最多可得到的 1.3 米钢柱数为

$$
\sum (6-2a_i)=6N-2\sum a_i=6N-600.
$$

为了得到 600 根 1.3 米钢柱，必须满足

$$
6N-600\ge 600,
$$

所以

$$
N\ge 200.
$$

构造方案：

- 100 根原材料按方式 A 切割，每根切 3 根 2.5 米钢柱，共 300 根。
- 100 根原材料按方式 D 切割，每根切 6 根 1.3 米钢柱，共 600 根。

因此最少需要 200 根原材料。

### 第 4 题：棋类跳跃问题

可将棋盘位置编号为 $0,1,\dots,k-1$，用一个 $k$ 位二进制状态 `state` 表示棋盘：第 $i$ 位为 1 表示有棋子，为 0 表示空位。

预处理所有合法跳跃三元组 $(u,v,w)$：棋子从 $u$ 跨过 $v$ 跳到 $w$。在状态 `state` 下，若 $u,v$ 有棋子且 $w$ 为空，则可执行：

$$
state' = state \oplus 2^u \oplus 2^v \oplus 2^w.
$$

其中 $u,v$ 从 1 变 0，$w$ 从 0 变 1。

回溯算法：

```text
DFS(state, depth):
    if depth == 13:
        if 不要求终点:
            输出方案
        else if state 只剩一个棋子且该棋子在初始空位:
            输出方案
        return

    for each move (u, v, w):
        if move is legal in state:
            apply move
            DFS(next_state, depth + 1)
            undo move
```

剪枝：

- 若剩余合法跳跃数为 0 且还未提走 13 颗，直接回溯。
- 用哈希集合记录 `(state, depth)`，避免重复搜索。
- 对第 2 问，可在深度接近 13 时检查目标空位是否仍可能成为最后位置。

分支限界法也可使用相同状态表示，把活结点放入队列或优先队列；优先级可取“已提走棋子数多”“距目标空位更近”等启发式。回溯法空间通常为搜索深度量级，分支限界法可能保存较多活结点。
